# 06 — UI / UX

極簡。無輸入。漢堡不開功能。

## 共用頂欄

- 左側：主界面顯示「grateful.tw」；閱讀頁顯示「返回」
- 右側：漢堡圖示按鈕，`aria-label`「選單」。點了沒有選單、沒有提示文案。

## 路由

| 路徑 | 畫面 |
| --- | --- |
| `/` | 主界面：日記列表 |
| `/journals/:id` | 該篇閱讀 |
| `/today` | 重導向 `/journals/affirmation-1` |
| 未知 id | 重導向 `/` |

## 主界面

- 列表最新在上
- 每列：標題（主文）＋建立日期時間（次要、較小）
- 整列可點，不要另做「閱讀」按鈕

## 閱讀頁

- 頂欄返回
- 標題下顯示建立日期時間
- 其後為該篇全文（第一篇結構同前：十一章 → 精簡版 → 九段結構）

## 空狀態

P0 至少有一篇，不做空列表畫面。
