# PRD — grateful.tw

**狀態：P0 為只讀呈現第一篇日記（2026-09-10）。未列的功能不要做。**

## 產品

- 名稱：grateful.tw
- 類型：私人感恩／肯定日記
- 端：Web（`apps/web`）+ Mobile（`apps/mobile`）
- 誰：先只有冠均自己。不是公開平台。

## 誰、核心流程、P0／非 P0

**核心流程：** 打開 App／網站 → 閱讀「冠均的 Affirmation」第一篇（十一章全文、每日精簡版、系統化九段說明）。

P0 **沒有輸入界面、沒有儲存、沒有登入、不接 Firebase。** `npm run start:web` 即可看到全文。

| 優先級 | User Story | 備註 |
| --- | --- | --- |
| P0 | 我打開網站就能讀到第一篇日記的完整內容（十一章、精簡版、九段式結構）。 | 只讀 |
| P1 | 自己撰寫／編輯日記 | 不做 |
| P1 | Email／密碼登入、Firestore | 延後 |
| P1 | 歷史列表 | 不做 |
| P1 | 推播、音訊、分享 | 不做 |
| P2 | 公開平台、他人帳號 | 不做 |

## 非目標（Non-goals）

- 輸入表單、九段填空、儲存按鈕
- 自建對外 REST `/api`
- 登入／Firebase
- 未寫進本 PRD 的欄位、流程、畫面
