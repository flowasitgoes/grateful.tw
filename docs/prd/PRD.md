# PRD — grateful.tw

**狀態：P0 為極簡只讀感恩日記（列表＋閱讀）。未列的功能不要做。**

## 產品

- 名稱：grateful.tw
- 類型：私人感恩日記
- 端：Web（`apps/web`）+ Mobile（`apps/mobile`）
- 誰：先只有冠均自己。不是公開平台。
- 調性：極簡。沒有多餘裝飾、沒有輸入。

## 誰、核心流程、P0／非 P0

**核心流程：** 打開網站 → 主界面格狀磁貼（最新在左上）→ 點一格 → 閱讀該篇全文。

P0 **沒有撰寫界面、沒有登入、不接 Firebase 資料。** 頂欄漢堡選單第一列連 Instagram。靜態 Web 暫部署 **Vercel**（連 GitHub `main`）。

| 優先級 | User Story | 備註 |
| --- | --- | --- |
| P0 | 主界面以格狀磁貼列出日記，最新在最前；可點進去閱讀。35 篇。 | 列表 |
| P0 | 每一篇有建立的日期與時間（資料仍保留；畫面暫隱藏不顯示）。 | 列表與閱讀頁 |
| P0 | 右上漢堡從右側滑出全高選單；第一列為 IG 圖示＋「riddles.tw」，開 https://www.instagram.com/riddles.tw | 選單 |
| P0 | 十一章、每日精簡版、系統化結構，以及 Day 14～35 短箋，共 35 篇只讀文稿。 | 只讀 |
| P0 | 全站與每篇有獨立文件標題與 description；閱讀頁標題含「感恩日記 Day n」，description 含主題詞，og:image:alt 為「篇名｜感恩日記」。 | SEO |
| P0 | 分享到 Facebook 等時，個別日記連結的靜態 HTML 含該篇 title／description／OG；每篇獨立 1200×630 字卡縮圖。 | SEO |
| P0 | 閱讀頁有上一篇／下一篇；Article／首頁 ItemList JSON-LD；Search Console 追蹤核心詞並可提交 sitemap。 | SEO |
| P0 | AI 搜尋友善：llms.txt、允許 AI 爬蟲、清楚的站點／篇目機器可讀摘要，利於 ChatGPT／Claude 等引用。 | SEO |
| P0 | 靜態 Web 能從 GitHub 部署到 Vercel（grateful.tw）。 | 部署 |
| P1 | 漢堡選單其他項目 | 不做 |
| P1 | 新增／編輯日記 | 不做 |
| P1 | Firebase、登入 | 不做 |

## 非目標（Non-goals）

- 輸入表單、儲存、登入、Firebase
- 漢堡選單第二列以後、設定頁、搜尋、標籤
- 自建 REST `/api`、Vercel Serverless 當產品 API
- 未寫進本 PRD 的功能
