# PRD — grateful.tw

**狀態：P0 已依 2026-09-10 決策定稿。未列的功能不要做。**

## 產品

- 名稱：grateful.tw
- 類型：私人感恩／肯定日記（九段式練習）
- 端：Web（`apps/web`）+ Mobile（`apps/mobile`，iOS／Android 同一套 Ionic build）
- 誰：先只有冠均自己。不是公開平台。

## 誰、核心流程、P0／非 P0

**核心流程：** 登入 → 打開「今天」→ 依九段填 1～3 句（可空）→ 儲存 → Web 與 Mobile 看到同一則。

兩端要同一本私人日記，因此 P0 含 Firebase Auth 與 Firestore 同步。不做匿名本機雙端各存一份。

| 優先級 | User Story | 備註 |
| --- | --- | --- |
| P0 | 身為唯一使用者，我能用 email／密碼登入 Web 與 Mobile，使兩端是同一帳號。 | Auth |
| P0 | 身為已登入使用者，我能看到「今天」的九段欄位；每段可填 1～3 句或留空。 | 主路徑 |
| P0 | 我能儲存今天這一則；重新打開（含換一端）仍是剛才存的內容。 | 同步 |
| P1 | 歷史列表／日曆回看過往日期 | 不做、不預留欄位 |
| P1 | 十一章長文 Affirmation 編輯／朗讀腳本 | 不做、不預留欄位 |
| P1 | 推播提醒、音訊、鏡子相機、分享 | 不做 |
| P2 | 多使用者公開平台、他人帳號、社群 | 不做 |

九段固定順序（不可增刪、不可改名以外的結構）：

1. 稱呼自己
2. 安全感
3. 自我接納
4. 能力
5. 關係
6. 創造
7. 金錢
8. 感恩
9. 今日意圖

每段一個文字欄。提示「1～3 句，可留空」。P0 **不做**句數硬驗證、也不做每段三個獨立 input。

## 非目標（Non-goals）

- 自建對外 REST `/api`
- 三套 UI
- 訪客／匿名登入、Apple 登入、多帳號切換
- 歷史列表、統計、標籤、搜尋
- 長文十一章、每日精簡版自動帶入（未列為 P0）
- 推播、FCM、相機、音訊
- 分享、公開、配對、聊天、代幣、管理後台
- 未寫進本 PRD 的欄位、流程、畫面
