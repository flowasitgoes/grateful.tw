# PRD — grateful.tw

**狀態：P0 為極簡只讀感恩日記（列表＋閱讀）。未列的功能不要做。**

## 產品

- 名稱：grateful.tw
- 類型：私人感恩日記
- 端：Web（`apps/web`）+ Mobile（`apps/mobile`）
- 誰：先只有冠均自己。不是公開平台。
- 調性：極簡。沒有多餘裝飾、沒有輸入。

## 誰、核心流程、P0／非 P0

**核心流程：** 打開網站 → 主界面看到日記列表（最新在最前）→ 點一篇 → 閱讀全文（含建立日期與時間）。

P0 **沒有撰寫界面、沒有登入、不接 Firebase。** 漢堡圖示只佔位，不開功能。

| 優先級 | User Story | 備註 |
| --- | --- | --- |
| P0 | 主界面列出日記，最新的排最前面；可點進去閱讀。 | 列表 |
| P0 | 每一篇顯示建立的日期與時間。 | 列表與閱讀頁 |
| P0 | 右上角有漢堡圖示，之後才加功能。 | 僅圖示 |
| P0 | 目前有一篇：冠均的 Affirmation（十一章、精簡版、九段結構）。 | 只讀 |
| P1 | 漢堡選單裡的功能 | 不做 |
| P1 | 新增／編輯日記 | 不做 |
| P1 | Firebase、登入 | 不做 |

## 非目標（Non-goals）

- 輸入表單、儲存、登入、Firebase
- 漢堡選單內容、設定頁、搜尋、標籤
- 未寫進本 PRD 的功能
